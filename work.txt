В организации используется процедура проверки компетенций сотрудников (ассессмент). 
Есть список требований к каждому уровню компетенций, который добавляет администратор.
Необходимо на основании требований к компетенциям создать список вопросов для сотрудника с использованием spring ai 2.0.0.
Сотрудник будет читать вопросы и отвечать на них голосом. Для первой версии достаточно возможности работы в браузере chrome.
Сервис должен быть реализован на java 25, Spring Boot 4.1.0, postgresql 18, React 19, Jooq, gradle. 
Для миграций используй liquibase. Файлы миграции в yaml-формате. 
Сервис должен записывать вопросы, ответы сотрудника и оценивать ответы по 5-и бальной системе. 
По каждому ответу давать рекомендации по развитию.
В конце предоставить сотруднику общую рекомендацию и оценить уровень компетенций (junior, middle, senior)
Административная часть должна быть закрыта логином и паролем администратора. 
Пользователь попадает на страницу по одноразовой ссылке, которая за ним закрепляется
